# 🥛 เปรม นมสด (Prem Nomsod) - Landing Page

เว็บไซต์ Landing Page สไตล์คาเฟ่สำหรับร้าน **"เปรม นมสด"** ร้านนมสดแท้ 100% ขนมปังปิ้งเตาถ่าน และบรรยากาศชิลล์ยามค่ำคืน

![เปรม นมสด](logo.png)

## 🌟 จุดเด่นของเว็บไซต์ (Features)
- **100% Mobile Responsive:** รองรับการแสดงผลทุกหน้าจออย่างสมบูรณ์แบบ ทั้งสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์
- **Modern & Cozy Cafe Aesthetic:** ดีไซน์โทนสีฟ้าพาสเทล ขาวนุ่ม และสีอบอุ่น พร้อมฟอนต์ Google Fonts ภาษาไทย `Prompt`
- **Interactive Menu Showcase:** การ์ดเมนูพร้อมปุ่มกรองหมวดหมู่ (นมสด, ปังปิ้ง, ปังเย็น, ของทานเล่น) และราคาชัดเจน
- **Full Atmosphere Gallery & Lightbox:** แกลเลอรีภาพบรรยากาศร้าน พร้อมระบบคลิกดูรูปขยายขนาดใหญ่
- **Interactive Google Maps Embed:** แผนที่นำทาง Google Maps ฝังในหน้าเว็บ พร้อมปุ่มขอเส้นทาง
- **Direct Facebook Integration:** ปุ่มเด้งไปหน้าเพจ Facebook ของร้านทั้งบน Navbar, การ์ดข้อมูลติดต่อ และปุ่มลอย (Floating Action Button)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5** โครงสร้าง Semantic Web
- **Tailwind CSS (CDN)** จัดการเลย์เอาต์ Responsive และ Styling
- **Font Awesome 6 (CDN)** ไอคอนต่างๆ
- **Google Fonts** ฟอนต์ Prompt
- **Vanilla JavaScript** สำหรับระบบ Lightbox, Filter เมนู, Mobile Menu Drawer และ Form submission

## 🚀 การติดตั้งและเปิดใช้งาน (Getting Started)
สามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้ง Server:
```bash
# ดับเบิลคลิกที่ index.html หรือเปิดผ่านเบราว์เซอร์
index.html
```
